# Mermaid図エディタ

ブラウザだけで動く Mermaid 図エディタです。`index.html` 1 ファイルで完結し、ビルドやサーバーは不要です（Mermaid 本体は CDN から読み込みます）。

## 主な機能

- リアルタイムプレビュー（パン・ズーム、エラー行のハイライト）
- 12 種類のテンプレート（フローチャート・シーケンス図・ER 図・ユーザージャーニー など）
- ジャーニー図の記述チェック（スコアの範囲、半角コロン、長いタスク名などを警告）
- SVG / PNG（最大 4x）書き出し、画像のクリップボードコピー
- 複数ドキュメントの自動保存（タブ間で同期、削除は元に戻せる）
- 圧縮した共有リンク、`.mmd` / Markdown の読込・保存
- ライト／ダークテーマ（OS 設定に追従）、図テーマの個別指定

## 使い方

`index.html` をブラウザで開くか、任意の静的ホスティングに置くだけです。

```bash
npm run serve   # http://localhost:8080
```

ショートカットは画面右上の「?」（F1）で確認できます。

## テスト

```bash
npm install
npm test
```

Playwright による E2E テスト（31 ケース）です。CDN へのリクエストを `node_modules/mermaid` に差し替えるため、オフラインでも実行できます。品質分析と各テストの意図は [docs/ANALYSIS.md](docs/ANALYSIS.md) を参照してください。

## 動作環境

最新版の Chrome / Edge / Firefox / Safari。共有リンクの圧縮には `CompressionStream` を使用し、未対応ブラウザでは非圧縮形式にフォールバックします。
