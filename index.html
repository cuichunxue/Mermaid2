Mermaid図エディタ — 使い方

ショートカット

  • Ctrl/Cmd + Enter レンダリング実行
  • Ctrl/Cmd + S 保存（自動保存を即時反映）
  • Tab / Shift + Tab インデント／解除（複数行可）
  • Ctrl/Cmd + / 行コメント切替（%%）
  • Esc → Tab エディタからフォーカスを移動
  • Shift + F 全体表示
  • ホイール 拡大縮小　ドラッグ 図の移動

機能

  • 複数ドキュメント管理（自動保存・複数タブ間で同期・削除は元に戻せる）
  • 行番号表示と構文エラー行のハイライト、ジャーニー図の記述チェック
  • SVG / PNG（最大4x）書き出し・画像のクリップボードコピー
  • 🔗 共有リンク（コードを圧縮してURLに埋め込み）
  • 📂 / 💾 .mmd ファイルの読込・保存
